## 学习提纲

- 事件的订阅模型：跟着 thread 走，不是全局广播
- turn 事件的粒度：item 增删改、token 用量、状态迁移
- 通知退订（notification opt-out）：前端可以只要自己画得出来的
- 实验性事件：fuzzy file search、realtime、Windows 沙箱安装
- 事件丢失时会发生什么（Lagged）
