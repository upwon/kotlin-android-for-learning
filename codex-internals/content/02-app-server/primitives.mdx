## 学习提纲

- thread：一条会话，有 id、有持久化、可 resume / fork / archive
- turn：一次「用户说话 → agent 干完活」的完整往返
- item：turn 里的最小可展示单元（消息、命令、diff、推理…）
- 它们和内核里 Session / Turn / ResponseItem 的对应关系
- 为什么前端应该按 item 增量渲染而不是按 message
