## 学习提纲

- stdio（JSONL）：IDE 扩展与大多数客户端的默认选择
- websocket：实验性，附带 /healthz 与 /readyz 探针
- unix socket：本地控制面，走 HTTP Upgrade 握手
- `--listen off`：只做 in-process，不开任何本地监听
- codex app-server proxy 与 stdio-to-uds 这两个中继
