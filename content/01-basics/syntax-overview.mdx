## 学习提纲

- 包声明与 import：目录结构不再强制对应包名
- 顶层函数与顶层属性：告别 XxxUtils 静态类
- 分号可省略、表达式优先的语法风格
- 注释与 KDoc

## 与 Java / Android 的关键差异

最直观的差异：类型写在名字后面、没有 new、分号可省。
