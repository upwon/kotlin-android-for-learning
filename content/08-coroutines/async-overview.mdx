## 学习提纲

- Android 上异步方案的演进：AsyncTask / Handler / RxJava / 协程
- 回调地狱与「用同步的写法做异步的事」
- 协程不是线程：它是可挂起的计算
- 为什么 Android 官方全面转向协程

## 与 Java / Android 的关键差异

协程解决的是 CompletableFuture / RxJava 想解决的同一批问题，但写法是顺序的。
