## 学习提纲

- if 作为表达式：取代三元运算符
- when 的四种形态（值、区间、类型、无参条件链）
- when 的穷尽性 exhaustive 与 sealed 的配合
- for + 区间 range：until / downTo / step / indices
- 为什么 Kotlin 没有 C 风格 for

## 与 Java / Android 的关键差异

switch 升级成 when：可匹配类型、区间、任意布尔条件，且有返回值。
