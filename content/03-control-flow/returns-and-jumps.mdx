## 学习提纲

- 三种跳转：return / break / continue
- 标签 label@ 与限定 break
- lambda 中的 return 是「非局部返回」
- return@forEach / return@label 的用法

## 与 Java / Android 的关键差异

lambda 里直接 return 会返回外层函数，这是 Java 匿名类没有的行为。
