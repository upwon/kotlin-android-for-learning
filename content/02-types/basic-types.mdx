## 学习提纲

- Int/Long/Double… 与 JVM 装箱的实际行为
- 没有隐式加宽转换：必须显式 toLong()
- 无符号类型 UInt/ULong
- 字面量、下划线分隔与位运算 shl/and/or
- Char 不再是数字

## 与 Java / Android 的关键差异

Java 的 int 与 Integer 在 Kotlin 里都写作 Int，装箱由编译器根据可空性决定。
