## 学习提纲

- `Array<T>` vs `IntArray`/`LongArray`（装箱差异）
- arrayOf / IntArray(n) { } 的构造方式
- vararg 与展开运算符 `*`
- 数组不支持型变：`Array<String>` 不是 `Array<Any>`

## 与 Java / Android 的关键差异

Android 里除性能敏感场景外，几乎总应该用 List 而不是数组。
