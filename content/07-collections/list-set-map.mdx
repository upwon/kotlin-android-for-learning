## 学习提纲

- List：索引访问、getOrNull、subList、二分查找
- Set：交并差 intersect / union / subtract
- Map：遍历、getOrElse、getOrPut、解构 (k, v)
- 可变集合的原地操作 removeAll / retainAll

## 与 Java / Android 的关键差异

Map 遍历可以直接解构成 (key, value)，比 entrySet() 干净很多。
