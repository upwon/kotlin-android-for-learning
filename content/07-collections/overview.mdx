## 学习提纲

- List / MutableList 的接口分离（不是不可变，是只读）
- listOf / mutableListOf / buildList
- 集合的型变：`List<out E>`
- 与 Java 集合互操作时的只读「假象」

## 与 Java / Android 的关键差异

Java 只有一套接口 + UnsupportedOperationException；Kotlin 在类型层面区分读写。
