## 学习提纲

- 函数类型 `(Int) -> String` 与函数类型的可空性
- lambda 语法、it、尾随 lambda
- 带接收者的函数字面量 `T.() -> Unit`（DSL 的基础）
- 匿名函数与 lambda 的 return 差异
- 闭包可以修改捕获的变量

## 与 Java / Android 的关键差异

Java lambda 只能捕获 effectively final 变量，Kotlin 没有这个限制。
