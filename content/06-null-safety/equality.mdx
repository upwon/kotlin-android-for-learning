## 学习提纲

- 结构相等 == 编译为 equals（含 null 检查）
- 引用相等 ===
- 重写 equals 时必须同时重写 hashCode
- 浮点数相等的特殊规则

## 与 Java / Android 的关键差异

和 Java 相反：== 是 equals，=== 才是引用比较。
