## 学习提纲

- 安全调用链与 `?.let {}`
- Elvis `?:` 与提前返回 `?: return`
- `!!` 的合理使用场景（几乎没有）
- 平台类型 `String!`：来自 Java 的隐患
- 可空集合的三种含义：`List<T>?` / `List<T?>` / `List<T?>?`

## 与 Java / Android 的关键差异

Android SDK 大量返回平台类型，注解不全时空安全会「漏气」。
