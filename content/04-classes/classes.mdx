## 学习提纲

- 主构造函数：声明与赋值一步到位
- init 块的执行顺序
- 次构造函数与 this(...) 委托
- 默认 final：类要显式 open 才能被继承
- 创建实例不需要 new

## 与 Java / Android 的关键差异

类和方法默认 final，这与 Java 默认可继承正好相反。
