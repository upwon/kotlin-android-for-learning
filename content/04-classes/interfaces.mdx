## 学习提纲

- 接口可以有默认实现和抽象属性
- 多接口默认实现冲突的解决
- fun interface：Kotlin 侧的单抽象方法接口
- SAM 转换：给 Java 接口传 lambda（如 OnClickListener）

## 与 Java / Android 的关键差异

Java 接口能直接传 lambda，但 Kotlin 自己的接口需要声明 fun interface。
