## 学习提纲

- 声明处型变 out（协变）/ in（逆变）
- 与 Java `? extends` / `? super` 的对照
- 类型投影与星投影 `*`
- 泛型约束 where
- reified 与 inline：绕过类型擦除（如 `startActivity<T>()`）

## 与 Java / Android 的关键差异

型变从「每次使用都写通配符」变成「在声明处写一次」。
