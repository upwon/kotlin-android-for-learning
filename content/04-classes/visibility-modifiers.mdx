## 学习提纲

- 四种可见性：public / internal / protected / private
- internal = 模块内可见，对应 Gradle module
- 顶层声明的 private = 文件内可见
- 没有 package-private

## 与 Java / Android 的关键差异

默认是 public 而不是 package-private；internal 很适合多 module 的 Android 工程。
