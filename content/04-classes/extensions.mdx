## 学习提纲

- 扩展函数的本质：静态方法 + 接收者参数
- 静态解析：扩展不参与多态，不能覆盖成员函数
- 扩展属性没有幕后字段
- 可空接收者 `T?.` 扩展
- Android 实战：View.dp、Context.toast、ViewGroup.inflate

## 与 Java / Android 的关键差异

Utils 静态方法的更好替代品；注意它是编译期静态分派。
