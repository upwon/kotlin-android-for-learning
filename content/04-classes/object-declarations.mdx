## 学习提纲

- 对象表达式 = 匿名内部类
- 对象声明 object = 线程安全单例
- companion object 与「Kotlin 没有 static」
- @JvmStatic / @JvmField 的互操作
- object 单例与 Android 生命周期/内存泄漏

## 与 Java / Android 的关键差异

static 成员统一由 companion object 承担，必要时用 @JvmStatic 给 Java 侧用。
